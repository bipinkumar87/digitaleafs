# Blog Images Directory
Place your blog images in this folder: `public/blogimg/`

To use an image in `public/blog.json`, simply reference it like this:
```json
"image": "/blogimg/your-photo.jpg"
```
Or with png/webp:
```json
"image": "/blogimg/tech-post.png"
```
Next.js automatically serves files from `public/` at the root URL path (`/blogimg/...`).
